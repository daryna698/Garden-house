# Сучасний будинок із садом (Three.js + Vite)

## Запуск
```
npm install
npm run dev
```

## Збірка та публікація на GitHub Pages
```
npm run deploy
```
Потім на GitHub: Settings → Pages → Branch: `gh-pages` / `(root)`.

## Структура
- `src/index.html` — сторінка з canvas і кнопкою звуку
- `src/style.css` — стилі
- `src/script.js` — уся сцена
- `static/` — текстури (Poly Haven, CC0; штукатурка й листя перефарбовані під цей проєкт)
